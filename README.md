# OLA Ride Bookings Analysis

## Project Overview

This project analyzes OLA ride booking data to understand booking performance, vehicle usage, revenue, cancellations, payment methods, and customer and driver ratings.

The analysis was performed using MySQL, and an interactive 5-page Power BI dashboard was developed to present key business insights.

## Tools Used

- MySQL
- Power BI

## Dataset

- Over 103,000 ride bookings
- 7 vehicle types
- Analysis period: July 2024

## SQL Analysis

Created 10 MySQL views using:

- Aggregate functions
- GROUP BY
- Filtering
- Sorting

The SQL analysis covers:

- Ride distance by vehicle type
- Top customers
- Cancellation reasons
- Customer and driver ratings
- Payment methods
- Successful booking value

## Power BI Dashboard

The interactive dashboard consists of five pages:

### Overall Analysis

Provides an overview of booking performance, booking status, and ride trends.

### Vehicle Type Analysis

Compares vehicle types based on booking value, successful booking value, and ride distance.

### Revenue Analysis

Analyzes revenue, payment methods, top customers, and booking value trends.

### Cancellation Analysis

Examines customer and driver cancellations and identifies major cancellation reasons.

### Ratings Analysis

Compares customer and driver ratings across different vehicle types.

## Key Insights

- The booking success rate was **62.09%**.
- Successful bookings generated approximately **₹3.51 crore** in booking value.
- Driver cancellations were influenced by personal and car-related issues.
- Cash and UPI were the most commonly used payment methods.
